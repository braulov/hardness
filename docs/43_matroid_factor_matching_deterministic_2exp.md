# Checkpoint 43 — Deterministic single-exponential matroid-constrained permutation matching

**Date:** 2026-11-02. **Branch:** PCC / tractable-union compatibility factors.
**Status:** Constructive algorithmic checkpoint, tested on small instances. The mathematical ingredients — determinantal sieving, exterior-algebra/representative-family dynamic programming, and folded-Wronskian rank condensers — are established prior art. **No originality claim** for the general algorithm or these lemmas. No general PCC→critical sparse 2-CSP compiler or PCC algorithm is constructed. Unlike Ferrers/Boolean factors, this new matroid layer does NOT automatically give an O(KlogK) exact CSP representation.

## 1. Linear-matroid constrained permutation matching (LM-PM)

Input: K rows, K columns, allowed positions E⊆[K]×[K], and for each (i,a)∈E an explicit vector v_{ia}∈F^d over a finite field F, with polynomially bounded d and efficiently computable field operations. Task:
   Is there π∈S_K such that (i,π(i))∈E for all i, and
   v_{1,π(1)},...,v_{K,π(K)} are linearly independent?

The associated single global factor is a **representable linear matroid** on candidate positions: the selected K-element set must be independent. Rainbow Perfect Matching is the special case v_{ia}=e_{c(i,a)} (standard unit vectors indexed by colors). It is a genuinely higher-order condition: three vectors e1,e2,e1+e2 are pairwise independent but jointly dependent.

## 2. Randomized 2^K determinant inclusion–exclusion (PROVED)

First assume d=K; larger d is handled by Section 4. Take formal random-indeterminate edge tags y_{ia}. For each subset S⊆[K], form the K×K matrix
   M_S(:,i) = Σ_{a∈S:(i,a)∈E} y_{ia} v_{ia}.
Define
   P(y)=Σ_{S⊆[K]} (−1)^{K−|S|} det M_S.

Multilinearity of the determinant along its K columns and elementary inclusion–exclusion imply
   P(y)= Σ_{π∈S_K, all (i,π(i))∈E}
            det[v_{1,π(1)},...,v_{K,π(K)}] · Π_i y_{i,π(i)}.
Indeed the inclusion–exclusion sum retains exactly tuples (a_1,...,a_K) using ALL K columns, hence exactly the permutations.

Different permutations give distinct edge-tag monomials, hence P is the zero polynomial iff every allowed perfect matching is matroid-dependent. Evaluating random y over a field of size >3K and using Schwartz–Zippel gives a **one-sided-error** O(2^K poly(K)) decision algorithm: if P(y)≠0 the answer is definitely YES, while if YES a nonzero polynomial of total degree K is not killed with probability ≥2/3. Preassigned forbidden positions are omitted.

For arbitrary d≥K, choose a random K×d projection A. A dependent K-set remains dependent, and any fixed independent K-set remains independent under A with probability ≥1−K/|F| by a nonzero K×K determinant polynomial. Combined with the edge-tag evaluation this gives one-sided randomized 2^K poly(K,d) time over a sufficiently large extension field. This construction is a direct application of *determinantal sieving* / randomized rank compression, not new literature.

Independent sanity tests: 500 random K×K vector matrices with K=2,...,6 over F_101 (vectors initially small integer coefficients), against exhaustive K! matchings; no false positives and no mismatches in the tested runs.

## 3. Deterministic exterior-span DP for K-dimensional representations (PROVED)

Let U=F^K. For S⊆[K], |S|=j, define
   W_S = span{ v_{1,a1} ∧ ... ∧ v_{j,aj} :
                   all (i,ai)∈E, {a1,...,aj}=S }
         ⊆ Λ^j U.
Start W_empty=span{1}⊆Λ^0 U. For j=0,...,K−1 and each S of size j, for every a∉S with (j+1,a)∈E, update
   W_{S∪{a}} ← W_{S∪{a}} + { w ∧ v_{j+1,a} : w∈W_S }.
Keep just a linear-algebra basis for each W_S. The update is linear in w and therefore retains exactly the span of wedge products generated by admissible partial matchings.

At the end W_[K]≠0 iff at least one selected matching has nonzero wedge product, i.e. has K linearly independent edge vectors. Because dim Λ^j F^K = binom(K,j), and there are 2^K states, all basis manipulations cost 2^{O(K)} poly(K) field operations (a coarse bound such as 2^{O(K)} suffices; constants in the base are NOT optimized). The algorithm is **deterministic**, works over arbitrary field characteristic, and uses exponential space. An actual witness can be recovered by standard self-reduction, fixing successive matching edges and rerunning the decision procedure.

Tested on 500 random instances K=2,...,6 against exhaustive permutation enumeration. No mismatch found.

## 4. Explicit deterministic rank condensation for d≫K (PROVED; standard folded Wronskian)

For d<K return NO. Identify vectors v∈F^d with polynomials
    f_v(X)=Σ_{j=0}^{d−1} v_j X^j.

Extend F if needed to a finite field F' of size poly(K,d,|F|) containing an element ω of multiplicative order at least d and at least K(d−1)+1 distinct nonzero evaluation points. Define the linear map
    Φ_t(v)=(f_v(t), f_v(ωt),...,f_v(ω^{K−1}t)) ∈(F')^K.

**Rank condenser property.** For ANY fixed independent K-tuple v_1,...,v_K∈F^d, the polynomial
    D(t)=det[ Φ_t(v_1),...,Φ_t(v_K) ]
is not identically zero and has degree at most K(d−1). Proof: by invertible column operations choose a basis of the K-dimensional polynomial subspace having DISTINCT degrees d_1<...<d_K. The coefficient of t^{Σ d_j} in D(t) is
    (Π_j lc(f_j)) det[ω^{(i−1)d_j}]_{i,j},
a nonzero Vandermonde because ω^{d_j} are distinct. Thus D(t)≠0. Therefore among any K(d−1)+1 distinct t-values some preserves the rank of this tuple; dependent tuples remain dependent under every linear Φ_t.

Enumerate the O(Kd) evaluation points t. For every t transform all input vectors by Φ_t and run the deterministic exterior-span DP of Section 3. If a solution exists then one t preserves a fixed witness; if no solution exists no transform can fabricate independence. Hence
    T_LM-PM(K,d)=2^{O(K)} poly(K,d,log|F|)
deterministically, under standard explicit finite-field arithmetic. To build a suitable extension deterministically for polynomial-domain inputs, choose its size to be poly(K,d), enumerate monic polynomials until finding an irreducible one (testable in polynomial time), and enumerate at most poly(K,d) field elements to locate an ω of order at least d (only O(d²) elements can have smaller order). In larger base fields, choose polynomially many explicit distinct elements directly. This is a standard *folded-Wronskian / rank-condenser* lemma, not a new invention.

Sanity checks: 160 random instances with K=2,...,5, d=K+2, over F_101; the deterministic condenser-family plus wedge DP agreed with exhaustive permutation testing.

Primary references: Forbes–Shpilka / Forbes–Guruswami folded-Wronskian rank condensers, https://www.cs.tau.ac.il/~shpilka/publications/ForbesSS13.pdf and https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.APPROX-RANDOM.2015.800 ; deterministic truncation of linear matroids https://sites.cs.ucsb.edu/~daniello/papers/deterministicTruncationTALG18.pdf .

## 5. Combining r linear-matroid factors and f Ferrers factors (PROVED)

Suppose the same permutation must:
- satisfy f supplied Ferrers/chain forbidden-edge factors as in [42](42_ferrers_chain_cover_and_rainbow_pcc.md);
- choose vectors independent in each of r supplied linear matroids (potentially different dimensions but over a common finite field, or fields embedded in a common extension).

Enumerate one permitted threshold for each Ferrers factor. There are at most (K²+1)^f threshold tuples after ordinal compression. For each tuple the allowed candidate positions E form a bipartite graph.

For r matroid layers, take for every partial matching the pure tensor
     (∧_{i≤j} v^{(1)}_{i,ai}) ⊗ ... ⊗ (∧_{i≤j} v^{(r)}_{i,ai})
in ⊗_{h=1}^r Λ^j F^K, after using rank condensers on each layer. Define W_S as the SPAN of all such tensors for matchings using column set S. Adding an edge is a linear map on the tensor space, so exactly the same basis DP is correct. A pure tensor is nonzero iff EVERY constituent wedge is nonzero, which is exactly simultaneous independence in all r matroids.

Dimension of the tensor space at layer j is binom(K,j)^r; there are 2^K subsets S. Thus for each fixed choice of rank-condenser maps the DP is deterministic in 2^{O((r+1)K)} poly(K). Enumerating up to poly(K)^r condenser choices can be absorbed in the 2^{O(rK)} term for polynomial ambient dimensions. Therefore
     T = 2^{O((r+1)K)} (K²+1)^f poly(input length)
is a **deterministic** decision algorithm, for explicitly supplied factors and efficient finite-field arithmetic. For CONSTANT r and f=O(K/log K) this is 2^{O(K)} poly(input). r=0 reduces to the polynomial perfect-matching test per Ferrers threshold, and f=0,r=1 yields the single-matroid algorithm.

**Crucial caveat:** this is a combinatorial/algebraic solver, NOT a sparse CSP compiler. A general linear independence predicate of K selected K-dimensional vectors may require a dense rank/determinant verification circuit if compiled naively into polynomial-alphabet binary constraints; no O(KlogK) exact CSP extension is claimed.

The randomized single-matroid version can use O*(2^K) determinant evaluations, while the deterministic multi-matroid exterior DP has a larger, unoptimized exponential base. Determinantal sieving in the literature has more sophisticated q-matroid-intersection bounds; our DP is a transparent special case.

Tested two-layer tensor-wedge DP on 200 random instances with K=2,...,5 (50 per K) vs exhaustive enumeration; no mismatch.

## 6. Separation from all previous pairwise covers

Take even K and candidate positions (i,a)∈(Z/KZ)^2. Partition them into K²/2 unordered pairs
   {(i,a), (i+K/2 mod K, a+K/2 mod K)}.
Give each pair a unique color, and forbid choosing both positions of the same color.

This is ONE partition-matroid independence constraint, represented by vectors v_{ia}=e_color (dimension d=K²/2). It is exactly the 'Rainbow' special case of our general algorithm, so it has a deterministic 2^{O(K)} algorithm via Sections 3–4.

The forbidden-pair graph H on all K² candidate positions is a perfect matching of K²/2 edges. Every forbidden edge has different rows AND columns, hence is genuinely co-selectable in a permutation. Its adjacency matrix has FULL rank K² over every field (a disjoint direct sum of [[0,1],[1,0]] blocks). A biclique or Ferrers/chain forbidden-edge factor can cover at most one of these edges, since any two edges induce a 2K2. Thus:
    matroid factors = 1;
    biclique-cover number = K²/2;
    Ferrers-factor number = K²/2;
    ordinary forbidden-matrix rank = K².
This is a strict separation in *representation parameters*. The particular example is not claimed to be computationally hard.

Linear-matroid independence is a genuinely higher-order factor (not merely a set of binary forbidden edges), e.g. e1,e2,e1+e2 have no dependent PAIR yet form a dependent triple.

## 7. Why this is NOT a universal PCC compiler (counting barrier)

Even ONE matroid factor of rank K with vectors v_{ia}∈F^K and field size |F|<=K^C has only K³ scalar coordinates of input-dependent data. Thus at most |F|^{K³}=2^{O(K³log K)} different exact acceptance predicates on the K! permutations can be represented in this very specific format.

As proved in [20](20_two_layer_affine_nonlinear_pcc_audit.md) and [40](40_lowrank_pcc_group_algebra_effective_rank.md), there is a family of genuine PCC inputs inducing 2^{Theta(K⁴)} distinct valid-permutation sets. Hence a single input-dependent rank-K matroid layer over a polynomial field CANNOT represent every PCC solution set exactly. The same argument excludes any CONSTANT number of such layers, and still applies if one uses a constant number of Ferrers factors with polynomial-size descriptions.

This does not exclude larger-dimensional matroids, multiple condensers (a rank-condensed OR over polynomially many K-dimensional tests), input-dependent existential auxiliary symbols, or general randomized **decision-only** compilers. It is NOT a lower bound on the main unrestricted problem.

## 8. Research status and suggested next target

**Positive:** One new robust factor class in the project — arbitrary explicitly represented linear matroid independence — admits randomized O*(2^K) and deterministic 2^{O(K)} perfect-matching algorithms, and combines cleanly with r=O(1) matroid layers and f=O(K/log K) Ferrers thresholds. It strongly extends color-equality/Rainbow factors, and is strictly beyond bounded forbidden-matrix rank, biclique cover and Ferrers cover.

**Limitation:** It yields NO new near-linear exact 2-CSP gadget for the matroid layer, and the general PCC still lacks the critical O(Ksqrt(log K)) compiler. Literature relevance is direct, especially Eiben–Koana–Wahlström, *Determinantal Sieving*, https://arxiv.org/abs/2304.02091 ; its broad matroid-sieving theorem already subsumes more general settings and this project does NOT claim priority.

**Best next constructive question:** Identify graph-dependent compatibility certificates that can be encoded as a CONSTANT number of matroid-independence tests on selected candidate positions **without preserving all original PCC solution sets** (decision-only), or show a concrete obstruction for a carefully specified such compiler. The strict score/solution-set counting barriers explain why exact universal factorization is unavailable at low description complexity.
