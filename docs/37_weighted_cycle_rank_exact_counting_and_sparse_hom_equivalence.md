# Rank-weighted cycle expansion and an algorithmic equivalence of sparse CSP with 2-degenerate HOM

**2026-11-02 research iteration.** PROVED elementary new-to-our-project algorithmic theorem and two-way fine-grained parameter transfer. This is NOT a single-exponential solver for all arbitrary sparse binary CSP, nor a new unconditional hardness lower bound. Novelty relative to the tensor-network/rank-decomposition literature is NOT asserted. This substantially strengthens the spanning-forest/fiber and Boolean-rectangle algorithms from note 36.

## 1. Exact weighted-forest theorem via matrix rank (PROVED)

Let I be an explicit binary CSP with v variables, m constraints, domain [q], and allowed-pair matrices A_e in {0,1}^{q x q}, with fixed orientation for each edge. Let r_e=rank_Q(A_e) (or rank over any field; choosing rationals makes exact integer #CSP unambiguous). If any r_e=0, I is UNSAT and #I=0 immediately.

For a spanning forest F of the primal graph define the **weighted algebraic cycle excess**

    mu_rank(I,F) := sum_{e in E\F} log_2(r_e)
    mu_rank(I)   := min_{F spanning forest} mu_rank(I,F).

**Theorem.** Exact #SAT(I), and hence SAT(I), is computable deterministically in

    2^{mu_rank(I)} * poly(v,m,q,L)

bit operations with polynomial bit space per summand (depth-first enumeration), after polynomial-time preprocessing of ranks and a maximum-weight spanning forest. Here L denotes complete relation-table encoding length. For connected instances max degree is not needed; for all components the algorithm processes component counts independently and multiplies them.

**Proof.** Fix F. For every chord e=uv not in F, compute an exact rational rank factorization

    A_e(a,b)=sum_{j=1}^{r_e} U_e(a,j) V_e(j,b).

The zero/one indicator of each chord is the sum over one mode j_e of a product of a unary weight on u and a unary weight on v. Distribute those sums over every chord:

    #I= sum_{(j_e:e notin F)} Z_F(j),

where Z_F(j) is the weighted partition function of a FOREST CSP, with the original arbitrary binary relations on tree edges, the original unary constraints, and vertex-specific rational weights generated by chord factors. Compute each Z_F(j) by usual rooted-tree sum-product dynamic programming in O((v+m)q^2) arithmetic operations (sparse tables may help). Summing exactly in Q yields the NONNEGATIVE INTEGER original #SAT; intermediate negative terms/cancellation cause no correctness problem when arithmetic is exact. The number of mode choices is prod_{e notin F}r_e.

Exact factorizations from nonzero minors can be obtained by Gaussian elimination. Their rational numerators and denominators have polynomial bit lengths via determinant bounds (0/1 matrices and q<=poly(L)); each intermediate weighted forest contraction and total accumulation has polynomially many bits because there are only poly(v,m,q) factors, each with polynomial-bit rational entries, and <=q^v assignments. This gives poly(L,v,m,q) bit cost per choice, and polynomial working space.

The exponent is minimized by a **maximum spanning forest** of G, giving each e weight log r_e (equivalently, sorting edges by r_e DESCENDING and applying Kruskal). Since the objective is sum_{e notin F}log r_e = constant -sum_{e in F}log r_e, greedy selection by numeric rank r_e is exact and polynomial-time; logs need not be evaluated.

**Universal bound:** r_e<=q, hence mu_rank(I)<=mu(G)log_2 q where mu(G)=m-v+cc(G) is cyclomatic number. Thus this recovers the elementary q^{mu(G)} cycle-cutset algorithm from note 13 but can be exponentially BETTER when some cycles have low-rank edge matrices.

Examples:
- if EVERY r_e<=r=O(1) and m=O(v), then #SAT is computable in 2^{O(v)}poly(L), even with dense/non-functional allowed relations and q=v^c;
- if a subgraph of all high-rank edges r_e>=q^epsilon has cyclomatic number Omega(v), then every forest leaves Omega(v) such high-rank chords, giving mu_rank>=Omega(v log q). This is a barrier to THIS rank-mode expansion, NOT a hardness proof; random dense tables are an example that can nonetheless be easy by greedy assignment.
- Equality edges have rank q but can be easy by direct propagation; rank is a sufficient algorithmic measure only.

## 2. Stronger Boolean-rectangle decision theorem (PROVED)

Suppose for each e a supplied cover of the ALLOWED relation is given:

    R_e=union_{j=1}^{b_e} (S_{e,j} x T_{e,j})

with b_e>=1. Fix a spanning forest F. Enumerate one rectangle index j_e for each NONFOREST edge e only. Each selected chord rectangle imposes two unary restrictions on its endpoints. All remaining constraints are arbitrary binary relations on the forest F, solved EXACTLY by ordinary tree CSP dynamic programming (Boolean OR/AND).

Therefore

    SAT time <= poly(L+sum_e b_e q) * product_{e notin F} b_e,

where F can be selected as a maximum spanning forest with edge weight log b_e, calculated by Kruskal using comparisons of b_e. The cover may overlap; correctness uses existential choice of an allowed rectangle, and counting is NOT directly given without inclusion-exclusion. This improves the earlier naive all-edge rectangle enumeration from note 36: only CYCLE edges need rectangle choices. It also improves the earlier hybrid forest-fiber algorithm whenever forest DP is used instead of pathwise branching.

For each of the two methods, an effective certificate of a 2^{O(v)} algorithm is mu_rank(I)=O(v) or mu_rect(I)=min_F sum_{e notin F}log b_e=O(v), respectively. Rectangle cover minimization within ONE matrix can be computationally hard; a supplied cover is sufficient. Matrix rank is computed in polynomial time, so mu_rank is a genuinely computable structural parameter.

## 3. Computational sanity test (DONE)

A direct sympy rational implementation of the rank decomposition, maximum-rank spanning forest and weighted forest DP was compared against brute-force #SAT on **250 randomly generated tiny CSPs** (v between 2 and 6, q between 2 and 4, including zero matrices, disconnected graphs and cycles). All exact integer counts matched. The first draft test code had an initialization bug for cases with a rank-zero chord; corrected to initialize the total to zero, reran the full suite, and obtained 250/250 matches. This sanity check is NOT a proof; proof is in Section 1.

## 4. Two-way algorithmic equivalence with 2-degenerate sparse-source HOM (PROVED, from note 35 reduction)

Define a *family-indexed single-exponential algorithm claim*:

(CSP-ALG) For EACH fixed c>=1 (and fixed density constant a), there is a deterministic 2^{O_{c,a}(v)}poly(L) solver for every binary CSP with v variables, at most a*v edges, q<=v^c. Equivalently one may restrict the constraint-graph maximum degree to 3 (using equality-path degree reduction on every variable and a fixed polynomial-alphabet enlargement/padding).

(HOM-ALG) For EACH fixed d>=1 and fixed density constant a, there is a deterministic 2^{O_{d,a}(n)}poly(n+h) solver for HOM(G,H) on simple loopless graphs with:
   n=|G|, h=|H|<=n^d,
   |E(G)|<=a*n,
   degen(G)<=2, degen(H)<=2.

**Theorem:** CSP-ALG iff HOM-ALG, with the same statement for bounded-error randomized algorithms.

**CSP-ALG -> HOM-ALG:** Regard HOM(G,H) as binary CSP with variables V(G), alphabet V(H) and one constraint E(H) for each edge of G. Number of constraints m=O(n). Degree-reduce each CSP variable u of degree d_u to d_u occurrence copies joined along an equality path, adding O(n+m) variables/constraints, max degree<=3. For isolated vertices and unary restrictions, straightforward single-variable handling. The target alphabet q=h<=n^d is <=(v')^c after suitable fixed polynomial padding, where v'=O(n) and c>=d; the expanded tables have polynomial size in h. Apply CSP-ALG to get 2^{O(n)}poly(n+h). Neither source nor target degeneracy is required for this direction.

**HOM-ALG -> CSP-ALG:** Given an arbitrary sparse binary CSP with v variables, m<=a*v, q<=v^c, apply the generalized pinning construction from our paper, fully reviewed in [note 35](35_general_sparse_binary_csp_to_2deg_hom_linear_source.md). Its exact parameters are

    n=255v+257m+251=O_a(v),
    h<=250(v+m)+251+5vq+7m q² = O_{a,c}(v^{2c+1}),
    |E(G)|=3(100(v+m)+100+2v+3m)=O_a(v)=O_a(n).

Both G and H are S_3 of base graphs, so BOTH have degeneracy at most 2 (every non-original vertex has degree 2; original vertices are independent). Thus the output is in HOM-ALG with some fixed d>=2c+1 and fixed source density a'. Apply the assumed HOM algorithm. Output construction is polynomial in the explicit CSP input length.

All quantifiers refer to **fixed polynomial exponents** and **fixed edge density bounds**. We do NOT claim a uniform 2^{C n} bound with C independent of arbitrary polynomial degree d or arbitrary growth of |E(G)|/n. For the randomized direction, the CSP->HOM and HOM->CSP reductions are deterministic, so error probabilities are preserved.

**Consequence:** At the scale of single-exponential algorithms, polynomial-alphabet sparse binary CSP and ordinary HOM with polynomial-size 2-degenerate target AND 2-degenerate sparse source are equivalent problems, up to fixed polynomial changes in target size. Equivalently, a failure of CSP-ALG for any fixed c (as conjectured by rNSE-SCSP(c)) forces a failure of HOM-ALG for some fixed d. Conversely a universal affirmative HOM-ALG family would refute every rNSE-SCSP(c). This is not a new reduction gadget: the nontrivial CSP->HOM direction is from our own paper.

## 5. Research implication

The surviving no-single-exponential hypothesis and HOM target are two faces of the SAME computational question. Work on algorithms for cubic CSP applies directly to sparse-source, 2-degenerate/2-degenerate HOM; conditional lower bounds transfer in the opposite direction.

The rank-weighted cycle parameter supplies a more targeted algorithmic project than generic rectangle/fiber attempts: identify structures where every cycle must contain many low-rank edges (or small rectangle-cover edges), and force mu_rank=O(v). The hard-looking residual class is one with Omega(v) independent cycles consisting entirely of edges with rank v^{Omega(1)}, plus no functional propagation and no dense-greedy win. Such restrictions are NOT known sufficient for hardness.
