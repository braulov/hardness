# Состояние программы (27 октября 2026)

**Сильная идея:** рассматривать задачи с глобальной связностью/ацикличностью как `линейная 3-CNF + одно условие на ранг выбранных столбцов графовой матрицы инцидентности`. Это математически строгое общее представление для FVS, Hamiltonian Cycle, Connected Dominating Set, Connected Vertex Cover и node-Steiner (на графах ограниченной степени), плюс некоторые комбинированные задачи.

Для `B_G` над `F_2` и выбранных рёбер `Y` имеем `rank(B_Y)=|V|-cc(V,Y)`.

- **FVS:** `y_uv=x_u AND x_v`; оставить `>= n-k` вершин; `rank(B_Y)=|Y|` (лес).
- **Hamiltonian Cycle:** выбрать по 2 ребра у каждой вершины; `rank(B_Y)=n-1` (один цикл).
- **Connected Dominating Set:** `y_uv=x_u AND x_v`; выбранное множество доминирует и непусто; `rank(B_Y)=|S|-1` (связность).
- **Set Cover:** взвешенные/групповые активации параллельных рёбер звезды дают ранг, равный числу покрытых элементов. **Но** при большом числе множеств это пока НЕ сохранение параметра `|U|`.
- **CNF-SAT:** одно ребро звезды на дизъюнкцию; активируется, если она истинна. `rank=m` iff формула удовлетворима. **Но** размер представления зависит от числа дизъюнкций и суммарной длины, а не только от числа переменных.

## Усиление: ОДНО условие полного порождения

С помощью двойственности графовых матроидов **FVS** записывается как полный ранг *кографического* матроида на рёбрах, затронутых удалёнными вершинами. Для задач на связность добавляем hub/root gadget (или бинарное дерево вместо hub для ограниченной степени), превращая связность выбранного индуцированного подграфа в полный ранг *фиксированного графового* матроида. Hamiltonian Cycle уже имел полный графовый ранг; SAT/Set Cover — полный ранг звезды с оговоркой о размерах. Значит, кандидат на базовую задачу — **Sparse (Co)Graphic Span-CSP**, где единственное глобальное условие: выбранные столбцы порождают весь (ко)графовый матроид. Подробное доказательство в `docs/09_full_span_matroid_conjecture.md`.

## Неожиданный выход: алгоритм для ЧЁТНОСТИ числа решений

Для каждого выбранного набора столбцов матроида число векторов в левом ядре равно `2^{дефицит ранга}`. Поэтому по модулю 2 вклад равен единице ТОГДА И ТОЛЬКО ТОГДА, когда полный ранг. Свидетели ядра кодируются локально: разрезы для графового матроида и эйлеровы подграфы для кографического. Отсюда **чётность количества FVS-решений или гамильтоновых циклов** сводится к #3-SAT с O(n) переменными и O(n) дизъюнкциями на разреженных графах. Это уже условное следствие опубликованного OpenAI #SAT-алгоритма, без схемы для ранга! Но чётность не решает существование: число решений может быть чётным.

Если удастся расширить #SAT-алгоритм на **взвешенный подсчёт над полем характеристики 2** с тем же показателем, случайные веса + Schwartz–Zippel дадут `2^{o(n)}`-алгоритмы поиска решения. Такое расширение ПОКА НЕ ДОКАЗАНО; подробности `docs/10_obstruction_parity_and_weighted_counting.md`.

## Win-win, но с правильными кванторами

**Алгоритмический выигрыш:** единый алгоритм `2^{o(n)}` для SGR-CSP даёт `2^{o(n)}` на все перечисленные *разреженные* частные случаи. Универсальная маленькая 3-CNF для ранга дала бы такой алгоритм из заявленной теоремы OpenAI.

**Гипотетический hardness-выигрыш:** предположение `SGR-CSP notin 2^{o(n)}` утверждает нетривиальную сложность очень специальной матроидно-локальной системы. Однако оно само по себе НЕ доказывает hardness всех включённых задач: для этого нужны редукции *SGR-CSP -> каждая задача* с линейным контролем параметра. Это сейчас главный открытый шаг ветки B.

**Сильнейшая ближайшая техническая цель:** схема `O(n log^{0.49} n)` булевых вентилей для проверки полного ранга/независимости выбранных столбцов матрицы инцидентности разреженного графа. Конструкция вместе с 3-SAT алгоритмом OpenAI даст `2^{o(n)}` для FVS и Hamiltonian Cycle на графах ограниченной степени.

## Обновление 2026-11-02: тензорное сжатие и закрытые источники hardness

**При условии корректности общей теоремы о свёртке булевых тензорных сетей** из октябрьского препринта OpenAI любой явный разреженный бинарный CSP с \(k\) переменными, \(O(k)\) ограничениями и \(q=k^{\Theta(1)}\) решается детерминированно за \(q^{O(k/\sqrt{\log k})}\operatorname{poly}(|I|)\). Точная редукция использует \(O(k\log q)\) булевых проводов, после чего применяет \(2^{O(M/\sqrt{\log M})}\)-теорему. Общая тензорная теорема **не** входит в документированную область Lean-формализации, поэтому следствия условны.

**Закрыто при этой предпосылке:** SPACH, rSPACH, CEH как гипотезы об отсутствии \(q^{o(k)}\)-алгоритмов; также основанные на них условные lower bounds для HOM и других задач. Сведения и кодировки остаются математически полезными.

**Закрыто как маршрут при одновременном принятии Circuit-SAT Hypothesis:** универсальный компилятор произвольного Circuit-SAT в \(O(s/\log s)\) переменных+ограничений с полиномиальным алфавитом, поскольку он дал бы \(2^{o(s)}\)-алгоритм для самой исходной задачи. Диапазон \(k+m=o(s)\), но не \(o(s/\sqrt{\log s})\), пока не исключён этим рассуждением.

**Не затронуто:** плотный PCC / PSCH, LogSAT-A/B, общая SCGS full-span задача, произвольный Circuit-SAT. **Приоритет:** независимый аудит тензорной теоремы. Полный разбор: [docs/33_tensor_contraction_sparse_2csp_and_hardness_triage.md](docs/33_tensor_contraction_sparse_2csp_and_hardness_triage.md).

## Дополнение: замена ETH и win-win на схемы

Формализм SCGS объединяет задачи через полное порождение графового или кографического матроида, но это пока НЕ полноценный преемник ETH. Для условных нижних оценок по каждой целевой задаче нужны линейные редукции **SCGS -> задача**, а имеющиеся кодировки дают преимущественно **задача -> SCGS**. General CNF-SAT и Set Cover имеют точные звёздные rank-кодировки без гарантии сохранения исходного параметра.

Из опровержения ETH уже следует `E^NP not subset SIZE(O(n))` (Williams); OpenAI заявляет усиление порядка `n sqrt(log n)`. Поэтому произвольное опровержение SCGS за `2^{o(n)}` не даст автоматически *новых* нижних оценок на схемы: нужны более сильные количественные алгоритмы, структурная полнота либо отдельный алгоритмико-схемный bridge theorem. См. `docs/11_eth_replacement_and_circuit_winwin.md`, включая сравнение с Williams (OVC and Nonuniform Circuit Lower Bounds).


## Ветка G — действительно новая замена ETH

Уточнение: сама SCGS-CSP — общее матроидное **описание** многих задач и кандидат на гипотезу об их сложности, но НЕ доказанная замена ETH с новым circuit win-win. Если есть быстрый SCGS-CSP, то 3-SAT тоже быстр (в локальную 3-CNF можно вложить исходную формулу), но известный вывод Williams `E^NP notsubset SIZE(O(n))` уже доступен из опубликованного заявления об ETH.

Для существенного нового исхода разумнее целиться в `NEXP notsubset P/poly`: Williams доказал, что достаточно алгоритма `2^n/n^10` для Circuit-SAT на `n` входах и схемах `n^k` вентилей **для каждого фиксированного k**. Поэтому новая задача: найти НЕ тривиальную форму полного графового/кографического ранга, которая через редукцию кодирует такие схемы, сохраняя `O(n)` *свободных входных бит*, даже когда структура имеет `poly(n)` размер; и обеспечить `2^{o(n)}poly(s)` алгоритм при опровержении предполагаемой сложности. Тривиальное разрешение произвольной Circuit-SAT в локальных ограничениях запрещено: так мы просто переименуем исходную задачу. Для lower bounds конкретных задач также нужны редукции из общего core **в эти задачи**, обратные существующим. Пока обе главные части не построены.

Полный план: `docs/11_eth_replacement_winwin.md`.

## Обновление 2026-11-03: сильная статистика CSP ≠ вычислительная hardness

[Заметка 47](docs/47_conditional_poisson_after_one_edge_and_endpoint_injectivity.md): в критическом случайном binary CSP (\(p=q^{-2/3}\), кубический граф) после удаления каждого ребра остаётся \((1+o(1))q^{2/3}\) решений с **попарно различными парами значений на концах удалённого ребра**. Поэтому при фиксировании остальных \(m-1\) таблиц число решений полной системы распределено **точно как** \(\mathrm{Bin}(N_e,q^{-2/3})\), асимптотически \(\mathrm{Poisson}(1)\). В разложении Хёффдинга *булевой функции UNSAT* почти вся ненулевая дисперсия приходится на компоненту, использующую все \(m\) таблиц.

**Существенное усиление и отрицательный контроль:** [заметка 48](docs/48_karger_cut_counting_conditional_poisson_and_easy_prism_counterexample.md) применяет классическую теорему Каргера о числе малых разрезов и убирает требования expansion и logarithmic girth из перечисленных **статистических** результатов: достаточно любого **3-edge-connected кубического графа** и полиномиального \(q=k^c\) с достаточно большой фиксированной \(c>9\). При этом кубические призмы \(C_s\square K_2\) обладают treewidth \(\le5\), и произвольный CSP на них решается за \(O(kq^6)\), но имеют всю ту же условную Poisson-статистику и полную фурье-степень SAT-бита. **Следовательно, эти свойства сами по себе НЕ поддерживают computational hardness-гипотезу.** Экспандерная структура нужна для большой treewidth, а источник hardness ещё предстоит обосновать отдельно. Барьеры для локального tree-lookahead по-прежнему могут требовать большого girth — не переносить их на призмы.

**Алгоритмическая цель:** на случайном кубическом **экспандере** научиться перечислять или почти равномерно сэмплировать только \(q^{2/3}\) решений CSP после удаления одного ребра, не перебирая экспоненциально много частичных присваиваний. Малый размер ответа не доказывает существование эффективного алгоритма; single-site Glauber динамика почти всегда застревает на изолированных решениях (см. заметку 47).


## Обновление 2026-11-03: что делать с полиномиально немногими near-solutions

**Структурное препятствие для наивного перечисления:** [заметка 49](docs/49_edge_deletion_treewidth_vs_near_solution_count.md) доказывает, что для кубического \(\gamma\)-экспандера после удаления \(t\) ограничений оставшаяся treewidth \(w\) удовлетворяет \(t+3(w+1)\ge\gamma k/4\). На критическом случайном распределении, если удалённые рёбра выбраны **до просмотра таблиц**, число решений оставшейся системы имеет точное ожидание \(q^{2t/3}\) и при большом полиномиальном \(q\) концентрируется. Поэтому нельзя одновременно добиться \(t=o(k)\) (немного решений) и \(w=o(k)\) (дешёвая стандартная динамика). Это не lower bound для глобального алгоритма перечисления.

**Hardness через единственное решение:** [заметка 50](docs/50_linear_parameter_random_isolation_to_unique_bipartite_cubic_csp.md) использует классическую Isolation Lemma и линейный по \(k\) набор бинарных сумматоров. После incidence-бипартизации и парсимонийного дополнения до 3-регулярности гаджетами \(K_{3,3}\setminus e\) получаем randomized Turing-редукцию из произвольного sparse 2-CSP с \(k\) переменными и полиномиальным \(q\) в **promise Unique-CSP на простом двудольном кубическом графе**, с \(K=O(k)\), \(Q=(kq)^{O(1)}\). Можно сделать и однократную randomized many-one редукцию с обратно-полиномиальной вероятностью изоляции. Следовательно, если принять **рандомизированную** \(\sqrt{\log}\)-SPACH, аналогичная hardness переносится даже на unique-or-unsat promise в точном исходном классе нашей HOM-редукции. Из детерминированной hardness это не следует; и это ничего не говорит о hardness конкретной iid случайной модели.

**Почему локальный sampler не годится:** [заметка 51](docs/51_near_solution_hamming_isolation_and_block_sampler_obstruction.md) доказывает, что для критического случайного CSP на кубическом экспандере с большим girth при достаточно большом \(q=k^c\) почти все из \(\Theta(q^{2/3})\) решений после удаления любого ребра отделены от всех остальных на расстояние **строго больше \(k/2\)**. Значит, feasible-only Markov sampler, меняющий не более половины переменных за шаг, почти всегда застрянет. Это не запрещает глобальный алгоритм, выходы в невыполнимые состояния или крупные блочные переходы.

**Реальная задача, которую не решили:** найти способ глобально перечислить \(q^{2/3}\) near-solutions на random expander за \(\operatorname{poly}(k,q)\) либо \(q^{o(k/\sqrt{\log k})}\), не используя ни низкую treewidth, ни локальные переходы по решениям. Параллельная worst-case программа: либо доказать randomized SqrtLog-SPACH/Unique-SqrtLog-SPACH, либо искать алгоритм Unique-CSP с показателем \(O(k/\log k)\), который через изоляцию перенёсся бы на общий sparse CSP и дал randomized single-exponential HOM при полиномиальном target и разреженном source. **Ни такого алгоритма, ни нижней оценки пока нет.**
